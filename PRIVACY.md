# Privacy Policy — Stoic Shorts Uploader

Stoic Shorts Uploader is a personal automation used only by its owner to upload videos to the owner's own YouTube channel.

- It requests a single Google permission: `youtube.upload`, used only to upload videos to the owner's channel.
- It does not collect, store, sell or share any personal data of any other user.
- OAuth credentials are stored as encrypted GitHub Actions secrets and are used only to perform the upload.
- Google user data is handled in line with the Google API Services User Data Policy, including the Limited Use requirements.
